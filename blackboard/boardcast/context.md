# Project: Boardcast

## Goal
Host the agent team's blackboard as a live web app so you can view task state, send messages to agents, and control the team from anywhere — not just localhost.

## Platform
Web (hosted) — React frontend + lightweight Node/Python backend, deployable to Railway / Fly.io / Vercel

## Tech stack
- Frontend: React + Vite
- Backend: Node.js (Express) or Python (FastAPI)
- Realtime: Server-Sent Events (SSE) or WebSocket
- Auth: token-based
- Deploy: Docker on Railway or Fly.io
